# 🔐 מדריך למפתחים: איך להוסיף סוד (Secret) ל־AWS — בלי Git ובלי לשלוח ל־DevOps

שלום! 👋  
המדריך הזה מיועד **למפתחים שזו הפעם הראשונה** שלהם עם טרמינל / Python.  
תעקבו שלב־אחר־שלב. אין מה לפחד — אם משהו נתקע, פשוט עצרו וכתבו ל־DevOps.

---

## מה אנחנו עושים כאן?

אנחנו שומרים סיסמאות / API keys / טוקנים ב־**AWS Secrets Manager**  
בסוד בשם:

```text
staging/app-secrets
```

✅ הסוד **לא** נכנס ל־Git  
✅ הסוד **לא** נשלח בצ'אט  
✅ הסקריפט **לא מוחק** סודות קיימים — הוא רק מוסיף / מעדכן מפתח אחד

---

## מה צריך לפני שמתחילים?

1. מחשב Windows (כמו שלכם)
2. גישה לקבצי הפרויקט (תיקיית `sbl-infrastructure`)
3. ש־DevOps כבר נתן לכם:
   - **AWS Access Key**
   - **AWS Secret Access Key**
4. Python מותקן (אם לא — ראו נספח בסוף)

---

## שלב 0 — פתיחת PowerShell (הטרמינל)

1. לחצו על מקש **Windows** במקלדת (או על כפתור Start)
2. הקלידו: `PowerShell`
3. לחצו על **Windows PowerShell** (או Terminal)
4. ייפתח חלון שחור/כחול עם טקסט — זה הטרמינל 🎉

> טיפ: אפשר גם ללחוץ ימין על תיקיית הפרויקט ב־Explorer → **Open in Terminal**

## שלב 1 — מעבר לתיקייה של הסקריפט

העתיקו את הפקודה הבאה **בדיוק**, הדביקו בטרמינל, ולחצו **Enter**:

```powershell
cd "$env:USERPROFILE\Desktop\DevOps Practicum\sbl-infrastructure\scripts"
```

### איך יודעים שהצלחתם?

הריצו:

```powershell
dir add_secret.py
```

אם אתם רואים את הקובץ `add_secret.py` — מעולה! ✅  
אם כתוב שלא נמצא — בדקו שהתיקייה `DevOps Practicum` באמת על ה־Desktop, או בקשו מ־DevOps את הנתיב המדויק.

## שלב 2 — התקנת הספרייה `boto3` (פעם אחת בלבד)

העתיקו והריצו:

```powershell
pip install boto3
```

לחצו **Enter** וחכו עד שזה מסיים.  
אם מופיע משהו כמו `Successfully installed` — מעולה.

אם `pip` לא מזוהה, נסו:

```powershell
python -m pip install boto3
```

---

## שלב 3 — חיבור ל־AWS (`aws configure`) — פעם אחת

> אם כבר עשיתם את זה בעבר — דלגו לשלב 4.

הריצו:

```powershell
aws configure
```

עכשיו המחשב ישאל אתכם 4 שאלות. ענו כך:

| שאלה | מה להקליד |
|------|-----------|
| `AWS Access Key ID` | המפתח שקיבלתם מ־DevOps |
| `AWS Secret Access Key` | הסודי שקיבלתם מ־DevOps |
| `Default region name` | `eu-north-1` |
| `Default output format` | פשוט לחצו **Enter** (ריק) |

✅ אחרי זה המחשב שלכם יודע לדבר עם AWS.

## שלב 5 — מה תראו על המסך? (מדריך אינטראקטיבי)

### 5.1 הודעת פתיחה
יופיע באנר יפה עם שם הסוד והאזור.  
לחצו **Enter** כדי להתחיל.

### 5.2 Secret Key (שם המפתח)
תשאלו משהו כמו:

```text
Secret Key (e.g. STRIPE_API_KEY):
```

הקלידו **רק את השם**, למשל:

```text
STRIPE_API_KEY
```

ולחצו **Enter**.

✅ מותר: אותיות, מספרים, קו תחתון `_`  
❌ אסור: רווחים או מקפים `-`

### 5.3 Secret Value (הערך הסודי) — תווים מוסתרים

תשאלו:

```text
Secret Value:
```

**חשוב מאוד:**  
כשאתם מקלידים / מדביקים — **לא תראו כוכביות ולא אותיות**.  
זה נורמלי לגמרי! 🙈  
Windows מסתיר את הערך כדי שאף אחד לידכם לא יראה אותו.

#### איך להדביק ערך מוסתר?
1. העתיקו את הערך ממקום בטוח (מנהל סיסמאות / מייל מאובטח)
2. בטרמינל: **קליק ימני** בעכבר (בדרך כלל מדביק ב־PowerShell)  
   או: `Ctrl + Shift + V` בחלק מהטרמינלים
3. לחצו **Enter**

### 5.4 אישור הערך (Confirm)
הסקריפט יבקש להקליד / להדביק **שוב** את אותו ערך.  
זה כדי למנוע טעות הקלדה.

אם הערכים לא תואמים — פשוט נסו שוב. אין בעיה 💪

### 5.5 אם המפתח כבר קיים
אם כבר יש `STRIPE_API_KEY`, הסקריפט ישאל:

```text
Type YES to overwrite...
```

- רוצים להחליף? הקלידו בדיוק: `YES` ולחצו Enter  
- לא בטוחים? הקלידו משהו אחר / Enter — **שום דבר לא יישמר**

### 5.6 הצלחה!
אם הכול עבד תראו משהו בסגנון:

```text
★★★  SUCCESS!  ★★★
```

🎉 מזל טוב — הסוד נשמר ב־AWS!

## תקלות נפוצות (ואיך להירגע)

### "AWS credentials were not found"
עדיין לא הוגדר `aws configure`.  
חזרו לשלב 3.

### "Permission denied"
למשתמש AWS שלכם אין הרשאה לסוד.  
כתבו ל־DevOps:  
> "צריך הרשאה ל־`staging/app-secrets` (GetSecretValue + PutSecretValue)"

### "boto3" / ModuleNotFoundError
הריצו שוב:

```powershell
pip install boto3
```

### הסקריפט נסגר מיד
נסו להריץ מתוך התיקייה הנכונה (שלב 1), או שלחו ל־DevOps צילום של השגיאה.

## אחרי שהוספתם סוד — מה הלאה?

1. הסוד נמצא ב־AWS ✅  
2. אם האפליקציה צריכה **משתנה סביבה חדש** (למשל `STRIPE_API_KEY`) —  
   תייגו את DevOps כדי לחבר אותו ל־Elastic Beanstalk / הקוד.  
3. **אל תעתיקו** את הערך לקבצים בפרויקט.

## נספח — התקנת Python (רק אם אין)

1. היכנסו ל: https://www.python.org/downloads/
2. הורידו את הגרסה האחרונה ל־Windows
3. בהתקנה סמנו ✅ **Add python.exe to PATH**
4. סיימו התקנה
5. פתחו PowerShell חדש ובדקו:

```powershell
python --version
```

צריך להופיע משהו כמו `Python 3.12.x`.
